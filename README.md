# astrbot_plugin_social_sim
「群友仿真」是移植自 qq-bridge 仿真规则的 AstrBot 插件，让 AI 像真人群友一样在群里说话。核心是观望、活跃、试探、退场的状态机：被点名才开口，活跃一阵主动收尾，冷场小概率试探，模型可输出 [SILENT] 潜水。配套三类记忆（话题、念头、群友印象，按 QQ 号存、跨群隔离）、从群聊统计出的语感画像、群友关系权重（谁老冒犯就少理谁）、按需识图、QQ 系统消息识别、叫停话题与自然遗忘，以及会自己复盘说话方式的人格迭代层。所有自动学习只追加在可控层，永不改动仿真规则与安全边界。零第三方依赖，放进 data/plugins 即可用。它追求的不是“回得更快”，而是“知道什么时候不回”。
